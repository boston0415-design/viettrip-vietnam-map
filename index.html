베트남맵을 홈 화면에

일상탈출 · 언제든, 한 번에

홈 화면에 추가한 아이콘을 누르면 지도가 바로 열립니다. 인터넷에 연결하면 열 때와 화면으로 돌아올 때 업소·후기를 다시 불러옵니다.

이용 방식
브라우저의 홈 화면 추가 기능입니다. 별도 APK 파일을 받을 필요가 없고, 추가 없이도 웹에서 이용할 수 있어요.
권한
‘내 위치’를 누를 때 위치 권한을 확인합니다. 홈 화면 추가 자체는 연락처·문자 권한을 요청하지 않아요.
공식 주소
viettrip-vietnam-map.pages.dev일상탈출 카페에 안내된 주소와 확인해 주세요.

카페·카카오톡 안에서는 추가 메뉴가 없을 수 있어요. 메뉴의 다른 브라우저로 열기를 누르거나, 아래 지도 주소를 복사해 Chrome 또는 Safari에서 열어주세요.

  1. Chrome에서 이 지도를 엽니다.
  2. 오른쪽 위 ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치를 누릅니다.
  3. 설치 / 추가를 확인하면 홈 화면에서 베트남맵 아이콘을 찾을 수 있어요.

메뉴 이름은 브라우저에 따라 다를 수 있습니다. 이미 아이콘이 있다면 그 아이콘으로 열어주세요.

  1. Safari에서 이 지도를 엽니다.
  2. 공유 버튼 → 홈 화면에 추가를 누릅니다. 공유 버튼이 안 보이면 페이지 메뉴에서 공유를 선택하세요.
  3. 웹 앱으로 열기가 보이면 켠 뒤, 오른쪽 위 추가를 누릅니다.

홈 화면에 추가 항목이 없으면 공유 메뉴 맨 아래 ‘동작 편집’에서 추가할 수 있어요.

  1. Chrome 또는 Edge에서 지도를 엽니다.
  2. 주소창의 설치 아이콘이나 브라우저 메뉴의 앱 설치를 선택합니다.
  3. 휴대폰에도 추가하려면 아래 주소를 휴대폰에서 열고 안드로이드 / 아이폰 안내를 따라주세요.

홈 화면 추가는 무료입니다. 지도 이용에는 인터넷 연결이 필요합니다.
